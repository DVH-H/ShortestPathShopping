How to load a Google Maps list
  1. One-time: add the Load list bookmark. On a computer, drag it to your bookmarks bar. On a phone, tap Copy bookmark code, save any page as a bookmark, and paste the code as its address.
  2. Open the shared list link in Google Maps (in the browser, not the app).
  3. Tap the Load list bookmark. You land back here with the list loaded.
